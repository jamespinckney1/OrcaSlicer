## Uncertainties and gaps

- **Fan %**: SUNLU publishes only 'On/Off' (wiki) or 'Open/Close' (TDS) for cooling, never a percentage, except LW-PLA (10%). `fan_pct` is therefore null for all other products; on/off state is in notes.
- **Drying hours**: product pages never give hours; the wiki gives hours for only some materials (PETG, ABS, PA, PC, PEEK, PCL). PLA-family and TPU drying hours are null. The uk.store High Speed Matte PETG listing adds 'S4/E2 dryer 65C for >=8h'.
- **High Speed ABS drying 50C** (wiki) is almost certainly a template error (all other ABS grades: 80C, 2-4h). Recorded as published but flagged.
- **TPU 90A**: sunlu.com's physical/mechanical table is a copy of the PLA table (density 1.23, tensile 40 MPa, HDT 55C) - clearly wrong for TPU, so density is null. Nozzle/bed/speed/drying come from the TDS and match the uk.store listing.
- **PCL**: product page says 75-85C nozzle and no heated bed; wiki says 130-150C nozzle, 20-40C bed. Product-page values recorded; the wiki values look like a different (older) grade.
- **Speed claims**: for High Speed PLA / PLA+ / PLA+ 2.0 / Matte PLA / Marble PLA / Matte PETG the spec table max (250-450 mm/s) is recorded, while marketing copy says 'up to 600 mm/s'. Wiki speed figures also differ from product pages for several items (PLA Lite, PLA Matte, HS PLA+, Marble, Wood, ABS-FR, PP, PA12-CF).
- **PLA Metal**: sunlu.com product page lacks a spec table; values are from the linked TDS (PLA-METALLIC, SL-TE-WI-132) and the store.sunlu.com listing.
- **PETG Rainbow**: exists only as a store.sunlu.com listing with no settings anywhere; all numeric fields null.
- **Enclosure / hardened nozzle**: set true only where SUNLU says so (enclosure: PC, PC-ABS, PEEK; hardened nozzle: PA6-CF, PA12-CF). SUNLU does not call for an enclosure on ABS/ASA (fan off + ventilation only). PETG-CF and ABS-GF are noted as 'nozzle prone to wear' without a hardened-nozzle requirement. Abrasiveness of glow/marble/wood/metal/glitter grades is not stated by SUNLU (`abrasive: null`).
- **Shore hardness**: SUNLU lists one 'HA/HD' number for rigid filaments without saying which scale; kept in notes. Silk TPU is described as 98A in copy but 97.5 in the table.
- **Amazon storefront**: amazon.com pages returned 503/403 to fetch. 'Sold by: SUNLU 3D Store' was confirmed on one listing. A third-party database of Amazon-verified SUNLU SKUs lists a few names NOT found on sunlu.com or store.sunlu.com: 'High Speed PETG' (non-matte), '95A High Speed TPU', 'Temperature Color Change PLA', 'Fluorescent PLA', 'Upgrade PLA' and 'Matte PETG CF'. These appear to be legacy/renamed or colour-collection SKUs (e.g. Fluorescent = PLA colour collection; Upgrade PLA = PLA+ 2.0) and are not given separate entries; High Speed PETG and High Speed TPU could not be verified on any official page.
- **Legacy names seen only on eBay/reseller listings** (not on any official store today): 'Easy ABS', 'Macaron PLA', 'TPU-SILK' (= Silk TPU, included). Not given separate entries.
- **Spool weights**: `spool_weight_g` is the filament net weight of the standard SKU (1000 g; 800 g for PP, PP 2.0, LW-PLA per store listings; PVB sold as 900 g removable / 1000 g ordinary spool). Most products are also offered in 0.25/0.5/2/3/5 kg.
- **Bed temp for PP 2.0** is a single value (40C) so min=max=40. PVA bed is '<70C' (min null).
